# MEOW PDF 리디자인 · 출시 기획

작성: 2026-10-01

## 제품 방향

단면 스캐너 전용 병합 도구를 누구나 쓰는 무료 로컬 PDF 작업실로 확장한다. 기존 양면 스캔 복원은 독립 도구로 유지한다. 핵심 약속은 회원가입·구독·워터마크 없이, 문서 서버 전송 없이 처리하는 것이다.

## 이번 출시 범위

| 도구 | 입력·옵션 | 결과 |
|---|---|---|
| PDF 병합 | 여러 PDF, 파일 순서 변경 | 단일 PDF |
| A4 일괄 변환 | 여러 PDF, 자동/세로/가로, 0/10/20 mm 여백 | 한 파일이면 PDF, 여러 파일이면 ZIP |
| 페이지 추출·재정렬 | PDF 하나, `3, 1-2` 등 페이지 선택 | 선택 순서의 PDF |
| 페이지 삭제 | PDF 하나, 삭제할 페이지 구간 | 나머지 페이지의 PDF |
| PDF 회전 | PDF 하나, 선택 페이지 또는 전체, 90/180/270도 | 회전한 PDF |
| 이미지 → PDF | JPG/PNG 여러 개, 순서 변경 | 비율을 유지한 A4 PDF |
| 양면 스캔 복원 | 앞면/뒷면 PDF, 역순/정순, 뒷면 180도 회전 | 교차 병합 PDF |

공통 흐름: 파일 선택 → 목록/순서/옵션 확인 → 실행 → 처음 6페이지 미리보기 → 명시적 다운로드. ZIP은 미리보기 대신 다운로드를 제공한다. 입력과 옵션을 변경하면 이전 결과를 폐기하여 잘못된 파일 다운로드를 막는다.

한 번에 총 200 MB까지 허용하는 메모리 보호 장치를 둔다. 유료 제한이 아니며, 이보다 작은 파일도 기기에 따라 실패할 수 있다. 암호화 PDF, OCR, 서명 검증, PDF→Office, 원본 보존을 보장하는 압축은 이번 범위에 포함하지 않는다. A4 재배치 시 주석/링크/양식 보존을 보장하지 않는다.

## 디자인

아이보리·연보라 배경, 반투명 패널, 얇은 밝은 테두리, 부드러운 이중 그림자로 글래스 뉴모피즘을 구현한다. 고양이 SVG와 종이 일러스트는 자체 코드로 제공한다. 네트워크 글꼴/CDN/트래커 없이 시스템 글꼴을 쓴다. 모바일 2열 도구 카드, 데스크톱 4열 카드, 키보드 포커스, 건너뛰기 링크, 상태 안내, 모션 감소 설정을 제공한다.

## 구조와 보안

Vite 다중 페이지 정적 빌드. `scripts/generate.mjs`가 도구·가이드·법적 안내 HTML과 검색 파일을 생성한다. 실제 처리 코드는 클릭 시 지연 로드한다. pdf-lib는 편집, PDF.js는 미리보기, fflate는 ZIP 생성에 사용한다. 문서를 전송하는 API, 로그인, 데이터베이스, 분석 스크립트를 두지 않는다. Vercel 응답 헤더로 외부 연결·프레임 삽입·플러그인 실행을 제한한다.

사이트 HTML과 자바스크립트 다운로드는 네트워크 요청이므로 “인터넷 통신 자체가 없다”라고 홍보하지 않는다. “PDF와 이미지의 내용 및 파일명은 업로드하지 않는다”가 정확한 약속이다. 현재 완전한 오프라인 재방문/PWA 설치는 지원 범위가 아니다.

## 검색 유입

홈과 7개 도구는 각기 고유 URL, 제목, 설명, canonical, OG, WebApplication 구조화 데이터를 갖는다. 본문과 내부 링크는 초기 HTML에 포함되어 자바스크립트 실행 전에도 읽힌다. 언어는 이번 리디자인에서 한국어를 기본으로 한다. 기존 영어 번역 데이터는 보관하되 새 도구의 영어 UI는 아직 제공하지 않는다. 다음 단계에서 `/en/` 정적 페이지와 실제 번역을 만든 후에만 hreflang을 추가한다.

- 도구: `/tools/merge/`, `/tools/resize/`, `/tools/extract/`, `/tools/delete/`, `/tools/rotate/`, `/tools/images/`, `/tools/duplex/`
- 검색 파일: `/robots.txt`, `/sitemap.xml`, `/rss.xml`
- 가이드: 병합, A4 일괄 변환, 양면 스캔 복원 3개 실제 본문
- 푸터: Privacy, Terms, Disclaimer, 사용 가이드, RSS, GitHub

RSS는 가이드 본문 전체를 포함하며 릴리스 때 실제 내용을 갱신한다. 허위 평가, 가짜 리뷰, 자동 갱신 lastmod, 실체 없는 수천 개 키워드 페이지는 생성하지 않는다. 검색 등록 절차는 SEARCH-LAUNCH.md를 따른다.

## 출시 검증

단위 테스트로 원본 순서, 추출 순서와 중복, 삭제 후 빈 문서 방지, 회전 합산, A4 네 방향, ZIP 충돌 없는 파일명, 이미지 변환, 오류 입력을 검증한다. Chromium 테스트로 실제 다운로드 PDF, 미리보기, 원격 문서 전송 없음, 모바일 overflow, 내부 링크, crop box와 회전을 가진 A4 결과를 확인한다. 실제 원본 문서와 iOS Safari, Firefox의 추가 확인은 운영 검증 항목으로 남긴다.

## 후속 확장 우선순위

1. 페이지 썸네일 드래그 재정렬과 선택 UI, 페이지별 PDF 분할 ZIP.
2. 영문 도구와 가이드, hreflang, 번역된 정책 안내.
3. 대용량 작업 진행률·취소, 제한된 메모리 기기의 작업 단위 개선.
4. PDF→이미지, 로컬 OCR은 별도 성능·정확도 검증 후 출시.

과도한 기능 수보다 기존 문서 품질과 처리 성공률을 우선한다. 출시 후에는 Search Console의 노출/색인 오류와 GitHub 이슈를 확인한다. PDF나 파일명 수집을 통한 제품 분석은 도입하지 않는다.
