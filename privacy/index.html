문서 처리

MEOW PDF는 선택한 PDF와 이미지의 내용, 파일명, 처리 결과를 서버에 업로드하지 않습니다. 파일은 현재 브라우저 탭의 메모리에서 처리하며 앱은 문서를 원격 저장소나 브라우저 영구 저장소에 저장하지 않습니다. 다운로드한 파일과 원본은 사용자의 기기에 남습니다.

접속 정보와 호스팅

웹페이지와 프로그램 파일을 제공하는 호스팅 서비스(Vercel)는 서비스 운영과 보안을 위해 IP 주소, 요청 URL, 접속 시각, 브라우저 정보 등 접속 로그를 처리할 수 있습니다. 이는 PDF 내용의 업로드와 다릅니다. 보관 기간과 처리 방식은 호스팅 제공자의 정책에 따릅니다.

쿠키 및 외부 서비스

현재 앱에는 광고, 행동 분석, 추적 쿠키를 사용하지 않습니다. PDF 라이브러리와 글꼴은 외부 CDN에 의존하지 않습니다. GitHub 등 외부 링크를 방문하면 해당 서비스의 정책이 적용됩니다.

메모리 해제

모두 지우기 버튼을 누르거나 탭을 닫으면 앱의 파일 참조를 해제합니다. 실제 메모리 회수 시점은 브라우저가 관리합니다. 기기에 저장한 파일은 직접 삭제해야 합니다.
