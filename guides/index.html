PDF를 원하는 순서로 합치는 방법 ↗

PDF 병합 도구에서 파일을 선택하세요. 목록의 위·아래 화살표로 파일 순서를 바꾼 뒤 실행합니다. 각 문서의 페이지는 원래 순서로 이어집니다. 결과 미리보기를 확인하고 다운로드하세요.

PDF 여러 개를 A4로 일괄 변환하는 방법 ↗

A4 일괄 변환에서 PDF를 여러 개 선택하세요. 자동 방향 또는 세로·가로 방향과 여백을 지정합니다. 원본의 비율을 유지해 A4 안에 맞추므로 내용이 잘리지 않습니다. 여러 파일의 결과는 ZIP으로 다운로드합니다. 링크·주석·양식 보존이 필요하면 원본을 유지하세요.

단면 스캐너로 양면 문서를 복원하는 방법 ↗

앞면만 스캔한 PDF를 먼저, 뒷면만 스캔한 PDF를 두 번째로 선택하세요. 일반적인 ADF 스캔에서는 뒷면이 역순이므로 기본 옵션을 사용합니다. 스캐너에 따라 정순 또는 뒷면 180도 회전을 선택하세요. 앞면이 한 페이지 더 많은 문서도 지원합니다. 결과 순서를 확인하고 저장하세요.
